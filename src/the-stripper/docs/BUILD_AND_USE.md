# The Stripper — Build, install, and use

How to build the plugin, install it in Reaper and use the editor.

---

## 1. Build (from repo root)

```bash
cd /path/to/fairy-tapes
git submodule update --init --recursive   # first time: fetch VST3 SDK, Airwindows, 4K-EQ (Dusk Audio), Pultec, etc.
bash build.sh the-stripper   # from repo root (fairy-tapes)
```

Or manually:

```bash
mkdir -p build && cd build
cmake ..
cmake --build .   # runs tests first, then builds the_stripper
```

**Output:** `dist/TheStripper.vst3/` (from repo root; folder containing the plugin). The build writes the bundle directly to `dist/`.

---

## 2. Install in Reaper (Linux example)

1. Find your VST3 path. Common locations:
   - Linux: `~/.vst3` or `/usr/lib/vst3`
   - Reaper can also scan a custom folder (Options → Preferences → VST).

2. Copy the **entire** bundle:
   ```bash
   cp -r dist/TheStripper.vst3 ~/.vst3/
   ```

3. In Reaper: **Options → Preferences → Plug-ins → VST** → (re)scan or add path if needed.

4. Insert the plugin on a track: **Insert → FX** → search "The Stripper" or "Fairy Tapes".

5. The plugin opens its own editor (1000 × 628, drawn by the code). The host's generic parameter list also works.

---

## 3. Using it

- **Strip Mode (CHAN / BUS):** Channel = 4K-EQ + Multi-Comp (Voice / Drums / Classic); Mix bus = Pultec (stub) + Multi-Comp Bus. The Voice/Drums/Classic buttons only exist in Channel mode.
- **IN buttons:** each module (filters share one, EQ, compression, drive, limiter, gate) has an IN button; lit = in the signal path. BYPASS (Output box) bypasses everything.
- **Drive:** click the paper strip in the Drive box to pick a `.nam` model (LOCAL tab: add folders, search, LOAD; NO MODEL unloads it and Drive passes the signal through). The model path is saved in the project.
- **Meters:** Level box (input/output peaks, gain reduction, one clip LED per stage; a click on a LED clears them all).
- **Reset:** double-click a knob to return to its default.
- Gain staging is inert (no control); Gate and Limiter are Airwindows (Denoise, BlockParty).

---

## 4. Developing

- Build in a scratch folder (the disk of the repo is small): `cmake -S . -B /tmp/ft-build -DCMAKE_BUILD_TYPE=Release -DGPU_NAM_DISABLE_CUDA=ON && cmake --build /tmp/ft-build --target the_stripper the_stripper_tests -j2 && ctest --test-dir /tmp/ft-build -R the_stripper`.
- **Linux dependencies of VSTGUI:** the X11/Cairo/Pango/fontconfig development packages (same list as `.github/workflows/build.yml`).
- Offscreen preview of the editor, no host needed: `cmake --build /tmp/ft-build --target the_stripper_render` then `the_stripper_render out.png [bypass] [bus] [eq-off] [meters] [model=<file>] [browser] [tone3000=<state>]` (`tone3000=` draws the TONE3000 tab with made-up data: unconfigured, signedout, signingin, list, tone, nc, download, error, ir, busy).
- The panel grain tile is generated by `tools/gen_panel_grain.py` (NumPy, Pillow; tests: `python3 -m pytest src/the-stripper/tools`).
